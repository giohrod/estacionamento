# 🅿️ EstacionaFácil

Sistema web de gestão de estacionamento, desenvolvido como projeto acadêmico da disciplina **Engenharia de Software – Aprendizagem por Projetos** (4º semestre ADS/SI, período 2026-2).

## 📌 Sobre o projeto

O **EstacionaFácil** tem como objetivo apoiar a operação de estacionamentos, centralizando em um único sistema web o controle de:

- Reservas e vagas
- Entradas e saídas de veículos
- Contratos (mensalistas)
- Serviços adicionais
- Pagamentos
- Avaliações dos clientes
- Indicadores de desempenho
